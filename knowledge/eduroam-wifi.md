# **Connect to eduroam Wi-Fi**

## We recommend using the [**Wi-Fi Onboarding Tool**](https://cloud.securew2.com/public/93210/eduroam/), which automatically configures your device for the CSULB wireless network. [Step-by-step instructions](https://csulb.teamdynamix.com/TDClient/1993/Portal/KB/Category/22337/Wi-Fi-for-Students-Faculty-and-Staff) are available for individual devices.  If you are unable to use the onboarding tool or prefer to configure your device manually, follow the instructions below.

## iOS Devices (iPhone and iPad)

**1.** Open Settings → Wi-Fi.

**2.** Select eduroam from the list of available networks..

**3.** Enter your CSULB email address and CSULB password.

4. Tap Join.

5. If prompted to review a certificate, tap Trust.

6. You are now connected to eduroam.

## Mac OS Devices

1. Open System Settings or System Preferences.

2. Select Wi-Fi. On older versions of macOS, select Network.

3. Select eduroam from the list of available networks..

4. Enter your CSULB email address and CSULB password.

5. Select OK. If prompted, review and trust the certificate.

6. You are now connected to eduroam.

\*NOTE:  If websites are slow to load, check that [Private Relay](https://support.apple.com/en-us/102022) is off for eduroam.  Disabling Limit IP Address Tracking should resolve many of the issues Apple users are experiencing on eduroam. 

From the Wi-Fi settings, click on the "..." icon to the right of the eduroam network and click on Network Settings from the pop-out window,

Toggle off the "Limit IP address tracking" setting and click the OK button.

## Android Devices

1. Open Settings → Wi-Fi.

2. Select eduroam from the list of available networks..

3. Enter or select the following settings:

4. Tap Connect.

5. If the connection fails, edit the eduroam configuration, expand the advanced options, and set MAC address type to Device MAC rather than randomized or private.

## Windows Devices

**1.** Open Settings.

**2.** Go to Network & Internet → Wi-Fi → Show Available Networks.

**3.** Select eduroam from the list of available networks..

**4.** Enter your CSULB email address and your CSULB password.

**5.** Select OK. If prompted to continue connecting, select Connect.

**6.** You are now connected to eduroam.
